# Fotos de catálogo de productos

Cada archivo `<SKU>.webp` de esta carpeta es la foto que la app muestra para el producto con ese SKU
cuando el producto no tiene una foto propia. Formato: cuadrado de 512 × 512 px, WebP, máximo 60 KB.

El brief con el estilo y la lista completa de productos está en `docs/brief-fotos-productos.md`.
